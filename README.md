# 青禾 · 实习生培养系统（GROW TOGETHER）

> 每个人的成长，都看得见。

面向开发 / 产品实习生的全周期培养管理系统。双岗位模型 × 三角色视角 × 过程数据自动沉淀，让培养有节奏、转正有依据。

## 核心特性

- **双岗位模型**：开发实习生 / 产品实习生一键切换，各自独立配置培养阶段、能力维度、转正评估体系
- **三角色视角**：带教导师（技术导师 / 产品导师，随岗位联动）、实习生、HR 组织管理员
- **全周期闭环**：培养总览 → 个人成长 → 成长任务 → 沟通与支持 → 阶段回顾 → 转正准备
- **转正考核版本化**：V1 维度权重评估（原体系） / V2 三维度必要条件（最新），两版内容均保留可查
- **量化产出追踪**：需求文档 / 需求澄清 / 竞品分析 / 数据运营 / AI 场景等必要条件达成度可视化
- **实习生管理**：添加 / 编辑 / 删除，实时联动全站数据
- **设计原则**：按入职阶段关注，不做排名

## 产品岗位转正必要条件（V2）

| 维度 | 必要条件 |
|---|---|
| 能力 · 子领域全流程 | 独立承担子领域完整闭环：规划 → 需求拆解/优先级 → 需求澄清落地 → 项目跟进 → 上线验收 → 数据运营 |
| 实践 · AI 场景 | 最少主导参与 2 个 AI 场景的设计、落地、演进 |
| 综合 · 量化产出 | 5 份需求文档 · 5 场需求澄清 · 2 份竞品分析 · 2 场数据运营（能通过数据识别问题并提出方案） |
| 加分项 | 沉淀 Skill 给团队使用 |

## 功能模块

| 视角 | 导航 |
|---|---|
| 带教导师 | 培养总览 / 个人成长 / 成长任务 / 沟通与支持 / 阶段回顾 / 转正准备 / 实习生管理 |
| 实习生 | 我的成长 / 我的任务 / 我的沟通 / 转正申请 |
| HR 管理员 | 组织看板 / 成长档案 / 转正流程 / 实习生管理 |

## 技术说明

- 纯前端单页应用（HTML + CSS + Vanilla JS），无任何依赖，双击 `index.html` 即可运行
- 示例数据内置，支持「重置示例数据」一键恢复
- 完整 PRD 见 [`docs/青禾实习生培养系统PRD.docx`](docs/青禾实习生培养系统PRD.docx)

## 本地运行

```bash
# 方式一：直接双击 index.html
# 方式二：本地静态服务
python -m http.server 8765 --directory .
# 浏览器访问 http://127.0.0.1:8765
```
